# TidyNest（拾净）

原生 macOS 应用，帮助你查看应用和磁盘占用，并在逐项核对后处理缓存、日志及支持的应用。使用 SwiftUI、AppKit 与独立维护引擎，复用 [Mole](https://github.com/tw93/Mole) 的查询能力和部分保护规则。

项目仍在开发打磨阶段，尚未正式发布。

## 当前功能

- **清理计划**：扫描可确认归属的缓存与日志，查看每项的路径、依据、影响与占用，再明确选择和确认。
- **应用管理**：搜索和查看应用详情，恢复上次列表，支持手动刷新完整列表、单个普通应用或已知 iPhone/iPad 包装应用的信息，并检查移除计划。
- **磁盘查询**：主动选择文件夹，查看占用、进入子目录、返回上层和定位文件。清理检查进行时也可同时使用。
- **操作记录与保护**：记录应用刷新、磁盘读取、计划检查和移除的类型与结果；支持删除单条、清空页面记录，以及设置长期保护项。
- **进度与取消**：检查展示当前应用及阶段，执行展示已处理数量，支持取消和等待任务收尾。

每次启动进入「应用」页，不自动扫描或刷新；应用页恢复上次列表，选中应用即可直接检查移除计划，检查时会重新核验当前应用与相关文件。手动刷新用于更新列表或单个应用的显示信息。

## 本地构建

需要 macOS 和 Swift 6 工具链；项目部署目标为 macOS 14 及以上，使用 Swift Package Manager，不依赖外部 Swift 包。已在 Apple Silicon、macOS 15.7.4、Xcode 16.4 上验证。

在项目根目录运行：

```sh
swift test
bash scripts/build-app.sh
```

构建产物为 `build/TidyNest.app`，可从 Finder 打开。打包脚本会同时构建主程序、独立引擎与资源，生成本机架构的 ad-hoc 签名 App。

运行时使用固定支持的 **Mole 1.53.0**。已有安装会自动检测；未找到时，可在 App 内主动点击安装，下载固定版本并校验摘要后安装到应用专属目录。不会自动升级 Mole 或修改 shell 配置。

## 使用方式

1. 打开 App，等待侧栏显示 Mole 已连接。
2. 在「清理」页点击「扫描缓存与日志」，或在「应用」页选中目标应用，直接点击「检查移除计划」。
3. 点击整行「检查提示」展开原因，查看每项路径和影响。应用本体可取消勾选，相关缓存与日志也会取消选择；确认所需项目后，再核对清单。
4. 确认后逐项移入废纸篓，在结果和「操作记录」中查看处理情况。

遇到占用提示时，可查看进程名称、PID 和具体文件路径。相关访问结束后，点击计划页的「重新检查此应用」更新结果，无需刷新完整应用列表。

磁盘查询可直接从「磁盘」页选择文件夹开始。清理检查期间仍可刷新应用列表或单个应用，以及刷新、删除和清空操作记录；取消记录读取不会停止清理检查。同一时间只生成一个维护计划，实际移入废纸篓需等待读取结束。主要操作结束后会出现在「操作记录」中，失败和取消也会记录；启动检测、搜索和选中项目不会产生记录。此前未记录的查询不会补录。删除或清空只移除页面记录，不改动应用、原文件或废纸篓；移除记录中的恢复位置也会从页面消失。

## 当前边界

- 维护范围是 Mole 规则的一个子集，不能视为完整的 Mole 图形界面或完整卸载器。
- 缓存和日志处理限能核实应用归属的普通文件：完整 Bundle ID 的 Caches/Logs 目录，以及已确认的包装应用容器内 Data/Library/Caches、Data/Library/Logs。应用本体限支持安装目录中的普通应用和已知 iPhone/iPad 包装应用，包装应用按整个外层包移入废纸篓。
- 上述缓存/日志中的数据库、会话、Cookie 或凭据类文件可手动勾选，默认不选；详情与最终确认会提示登录状态或本地数据丢失的可能影响，请自行判断并核对数据库配套文件。未勾选的文件保留；长期保护、占用及其他安全校验仍生效。
- 多版本应用按所选路径处理本体，共享缓存与日志保留；Xcode 仅支持本体移除，开发数据和其他 Apple 应用继续保留。应用包可由当前用户或系统账户拥有，处理仍受系统权限约束。
- 文稿、存档所在的 Documents/Application Support、偏好设置和共享容器保留。容器归属元数据不可读、重复或发生变化时不清理容器文件；部分链接布局、厂商管理或受保护项目仍不支持移除，检查不完整时不执行计划。
- 应用或后台进程仍在运行、可写文件、目录及无法判断的文件映射会保留并说明原因。仅移除整个应用本体时，已确认的外部只读普通文件访问可以通过检查；缓存和日志仍要求解除占用。
- 动作仅为移入废纸篓，不会立即释放磁盘空间。暂不提供自动恢复；如需恢复，应按操作记录中的原路径手动移回。Finder 的「放回原处」可能指向私有暂存目录。
- macOS 14 实机、Intel、正式发行签名与公证、受隐私权限保护目录尚未完成验收。
