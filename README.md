# TidyNest（拾净）

原生 macOS 应用，帮助你查看应用和磁盘占用，并在逐项核对后处理缓存、日志及支持的应用。使用 SwiftUI、AppKit 与独立维护引擎，复用 [Mole](https://github.com/tw93/Mole) 的查询能力和部分保护规则。

项目仍在开发打磨阶段，尚未正式发布。

## 当前功能

- **清理计划**：扫描可确认归属的缓存与日志，查看每项的路径、依据、影响与占用，再明确选择和确认。
- **应用管理**：搜索和查看应用详情，恢复上次列表，支持手动刷新完整列表或单个普通应用，并检查移除计划。
- **磁盘查询**：主动选择文件夹，查看占用、进入子目录、返回上层和定位文件。
- **操作记录与保护**：保留本地处理结果，设置长期保护项。
- **进度与取消**：检查展示当前应用及阶段，执行展示已处理数量，支持取消和等待任务收尾。

每次启动进入「清理」页，不自动扫描；应用页恢复上次列表，需手动刷新。缓存中的应用须在本次会话成功刷新后，才能检查其移除计划。

## 本地构建

需要 macOS 和 Swift 6 工具链；项目部署目标为 macOS 14 及以上，使用 Swift Package Manager，不依赖外部 Swift 包。已在 Apple Silicon、macOS 15.7.4、Xcode 16.4 上验证。

在项目根目录运行：

```sh
swift test
bash scripts/build-app.sh
```

构建产物为 `build/TidyNest.app`，可从 Finder 打开。打包脚本会同时构建主程序、独立引擎与资源，生成本机架构的 ad-hoc 签名 App。

运行时使用固定支持的 **Mole 1.53.0**。已有安装会自动检测；未找到时，可在 App 内主动点击安装，下载固定版本并校验摘要后安装到应用专属目录。不会自动升级 Mole 或修改 shell 配置。

## 使用方式

1. 打开 App，等待侧栏显示 Mole 已连接。
2. 在「清理」页点击「扫描缓存与日志」，或在「应用」页刷新目标应用后点击「检查移除计划」。
3. 查看计划中的每项路径和影响，勾选所需项目，再核对确认清单。
4. 确认后逐项移入废纸篓，在结果和「操作记录」中查看处理情况。

磁盘查询可直接从「磁盘」页选择文件夹开始。

## 当前边界

- 维护范围是 Mole 规则的一个子集，不能视为完整的 Mole 图形界面或完整卸载器。
- 首批缓存和日志处理限能核实应用归属的完整 Bundle ID 目录中的普通文件。应用本体限支持安装目录中的普通应用。
- iPhone/iPad 包装应用、部分链接路径、厂商管理或受保护项目目前不支持移除；检查不完整时不执行计划。
- 动作仅为移入废纸篓，不会立即释放磁盘空间。暂不提供自动恢复；如需恢复，应按操作记录中的原路径手动移回。Finder 的「放回原处」可能指向私有暂存目录。
- macOS 14 实机、Intel、正式发行签名与公证、受隐私权限保护目录尚未完成验收。

默认测试使用隔离 fixture。系统废纸篓与联网安装验收需显式启用，不属于默认测试范围。具体命令和实际验收记录见 [AGENTS.md](AGENTS.md)。

| 目录 | 内容 |
