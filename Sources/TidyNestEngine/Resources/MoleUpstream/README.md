原项目许可为 GPL-3.0-or-later，原文保留在 `LICENSE`。`source-manifest.json` 记录摘录的原始文件、行段与摘要。`.txt` 文件是原文审计摘录，程序不执行其中的 shell 内容。`protection-data.json` 从固定源码的静态数组提取，保留上游字段名，供派生规则使用。

TidyNest 的首批规则将通用用户缓存和日志扫描收窄到能够核实归属的完整 bundle ID 目录；排除系统、厂商管理、共享、编译模型等范围。缓存/日志中的数据库和会话等持久状态文件按 TidyNest 用户确认的规则作为可选项，默认不勾选，并在操作影响中说明风险。保护数据与相关算法在 Swift 中移植，文件快照、计划存储和逐项执行由 TidyNest 实现。它不是原版 `mole clean`，也不承诺原版所有规则都已移植。

与原版缓存删除不同，首批动作统一移入系统废纸篓，失败不退回永久删除。移植内容及具体边界见项目 `docs/m2-plan.md` 和 Swift 引擎实现。

本目录的许可材料不代表已完成整个项目的对外开源发布、签名或公证。
